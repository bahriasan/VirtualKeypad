# VirtualKeypad
Virtual Keypad provides touchpad and/or hovering features to existing keypad
Has 2 Parts:
Virtual Keypad developed in QT Widgets for Desktop
Works on Windows
Keypad to PC USB connection over STM Discovery Card(STM32F407VE)
Handles keypad inputs and converts them to USB messages to simulate keypad
Custom USB Driver on STM32F407VE
Doesn't need a driver on Windows side
